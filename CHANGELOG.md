## v2.2 — 27 October 2026 (affiliate links + social profiles)

Requested: add affiliate links at any time, keep everything fully editable/customisable, make sure a
visitor who clicks an affiliate link actually lands on the retailer, be able to add/customise products,
and wire up the two social profiles.

### Affiliate links — add or remove any time
- New `src/lib/affiliate.ts` normalises whatever you paste: `https://store.com/x`, `store.com/x` and
  `www.store.com` all become a working link. Empty stays empty — nothing is ever invented.
- Product cards, review pages and search results render a real CTA the moment a URL exists:
  **“Check price” / “Check current price” → opens the retailer in a new tab** with
  `rel="sponsored nofollow noopener noreferrer"`, and the disclosure sits directly beside the button.
- Clear the field and the button returns to the disabled “Link not set” state instantly.
- Studio Manager product editor now shows live link status: **“Live on the site”**, the host it will
  open, and a **Test link** button — so you can confirm a URL before publishing.

### Products — add and customise
- `/manager` → Products → **Add product**, then edit name, slug, brand, garment type, category, image URL,
  summary, description, specs, pros/cons, retailer, price, price-checked date, affiliate URL and the
  demo / featured / price-verified / hands-on flags. Delete is one click. Export `products.ts` to make it
  permanent, or use Export / Backup for a full JSON.

### Social profiles — added
- **Facebook** → https://www.facebook.com/ThreadTrendStudio
- **Pinterest** → https://www.pinterest.com/threadtrendstudioofficial/
- New Pinterest icon + `SocialLinks` component. Icons appear in the **footer on every page** and in a
  new “Follow the studio” row on the **Contact** page. Both open in a new tab with
  `rel="noopener noreferrer"`; channels with an empty field are not rendered at all (no fake accounts).
- `SocialLinks` type extended with `pinterest`; Manager Settings and the settings export snippet updated.

### Docs
- README: new “Editing checklist” table (what is live immediately vs. needs a rebuild), §6.1 “How the
  link behaves for visitors”, §6A “Social profiles”, updated file tree and sitemap count.

### Verification (Chromium, both breakpoints)
- Manager: pasted a bare-domain affiliate URL → “Live on the site” + Test link, CTA appeared on home,
  review page and stayed after reload; clearing it restored the disabled state; “Add product” went 13 → 14.
- Footer + Contact social icons resolve to the two supplied URLs with `target="_blank"`.
- 21 URLs at 1440 px and 390 px: 0 broken images, 0 missing `alt`, 0 overflow, one `<h1>`, 0 console errors.
- `tsc --noEmit` clean, `vite build` clean, offline single file verified again.
